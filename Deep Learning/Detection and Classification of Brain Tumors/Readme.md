# 🧠 Reconocimiento y Clasificación de Tumores Cerebrales con Redes Neuronales Convolucionales (CNN).

## 🎯 Objetivo.
El objetivo fue desarrollar y comparar varios modelos de redes neuronales convolucionales (CNN) para analizar su desempeño, precisión y costo computacional.

## 📊 Desarrollo.
Planteamos diferentes enfoques para la construcción de cada CNN, evaluando la precisión y la capacidad de generalización. Por último implementamos métodos de procesamiento de imágenes lo cual logró aumentar la cantidad de datos disponibles y mejorar la robustez del modelo.

## 📍 Conclusión.
Todo el trabajo derivo en un modelo capaz de clasificar tres tipos de tumores con una precisión superior al 93%. 

🙌 Este proyecto nos permitió afianzar conocimientos y profundizar en el uso de CNNs, señalando la importancia de ser cuidadosos a la hora de construir un modelo. A su vez nos brindo la experiencia de llevar nuestros conocimientos a otro campo tan interesante como el de la medicina.
